# 🚀 Guide de Déploiement : ASIN OEM Sourcing Hub

Votre application est prête. Pour l'utiliser sur votre téléphone via un lien permanent, voici les deux options les plus simples :

## Option 1 : Déploiement Permanent (Gratuit & Recommandé)
Cette option vous donne un lien `https://...` utilisable partout sur votre smartphone.

1. **Vercel ou Render** :
   - Connectez votre compte GitHub (si vous en avez un).
   - Importez ce dossier de projet.
   - Le site sera automatiquement en ligne.
   - *Alternative : Je peux vous aider à configurer un déploiement direct via le terminal.*

## Option 2 : Test Rapide sur votre Wi-Fi (Local)
Si votre Mac et votre Téléphone sont sur le même réseau Wi-Fi :

1. Dans le terminal Accio, lancez : `npm start`
2. Trouvez l'adresse IP de votre Mac (ex: `192.168.1.15`).
3. Sur votre téléphone, ouvrez le navigateur et tapez : `http://192.168.1.15:3000`

## Rappel des Critères Configurés
- **Exact Match** : Recherche ciblée sur l'usine officielle.
- **Volume** : > 50 ventes / mois.
- **Sécurité** : > 5 vendeurs pour éviter le Private Label bloqué.
- **ROI** : > 50% minimum.
